## 验证清单（改造后）

- [ ] `pnpm/npm run build:<env>` 产物资源为相对路径
- [ ] 平台出现构建版本并可预览
- [ ] 深链刷新不 404
- [ ] 登录/OAuth 回调域名正确（等于用户实际打开的域名）
- [ ] 主要 API 无 CORS 失败
- [ ] （模板 A）平台 URL 可打开；`__APP_BASE__` 与 pathname 一致
- [ ] （模板 B）旧域/旧 path 可打开；反代到正确 env；`VITE_APP_BASE_NAME` 与地址栏前缀一致
- [ ] （若内嵌小程序）webview 可打开；白名单/安全域名已切；授权回调不回失效旧域
- [ ] （若做了 upload-assets）CDN URL 可访问（字段 `cdnDomain`）；页面引用已切；展示图经资源右侧 **处理** 预览后带合理 `image_process`；增量再跑只传变更文件
