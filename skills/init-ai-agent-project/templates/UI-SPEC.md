## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 清晰优先 | 信息层级可辨；避免无意义的装饰。 |
| 平台体感 | 对齐目标平台常见交互与视觉习惯。 |
| 触控友好 | 可点击区域足够大；固定操作区注意误触。 |
| 性能可落地 | 长列表虚拟化或分页；不牺牲滚动稳定性。 |
| 状态可感知 | 加载、禁用、空态、错误态对用户可见。 |
