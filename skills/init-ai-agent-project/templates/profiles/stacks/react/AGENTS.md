## 技术栈规则：React

- 默认使用函数组件、TypeScript 与 Hooks；遵循仓库既有路由、数据请求、表单和状态方案。
- 服务端状态、跨页客户端状态和组件局部状态分开管理；能派生的数据不重复存储。
- render 保持纯净；副作用只用于同步外部系统，并完整处理依赖、取消、竞态和清理。
- 不用 `useMemo`、`useCallback` 或全局 store 掩盖结构问题；性能优化必须基于测量或明确热点。
- 组件优先按用户行为测试，覆盖加载、空态、失败、权限和重复交互；避免只断言实现细节。
- 变更 Next.js/SSR 项目时确认 Server/Client Component 边界、缓存、序列化和 hydration 行为。
