## 技术栈规则：微信小程序

- 遵循 `app/page/component` 生命周期与原生目录约定；不要把 Web DOM 或浏览器 API 假设带入小程序。
- `setData` 只传视图需要的最小数据，避免高频、大对象和深层全量更新；派生逻辑留在逻辑层。
- 网络、登录、授权、隐私与支付能力必须处理拒绝、超时、重复回调、前后台切换和基础库兼容。
- 页面与组件通过 properties/events 或明确的数据层通信，禁止依赖隐式跨页可变状态。
- 控制主包与分包体积，图片和资源按设备像素、缓存与弱网场景优化。
- 验证至少覆盖开发者工具和一台真机；记录基础库版本、机型/系统与未覆盖能力。
