# 项目开发宪法

# Version: 1.0, Ratified: YYYY-MM-DD

本文件定义本项目不可动摇的核心开发原则。所有 AI Agent 在技术规划与代码实现时必须遵循。

---

## 第一条：简单性原则 (Simplicity First)

**核心：** 少即是多。不做不必要的抽象，不引入非必需依赖。

- **(YAGNI):** 只实现需求明确要求的功能。
- **(原生优先):** 优先使用语言与标准库能力，新依赖须说明理由。
- **(反过度工程):** 简单函数与数据结构优于复杂层次。

---

## 第二条：测试先行 (Test-First)

**核心：** 新功能或 Bug 修复从失败测试开始（若项目已有测试体系）。

- 遵循 Red-Green-Refactor。
- 优先表格驱动或参数化测试覆盖边界。
- 集成测试优先于过度 Mock（按项目实际情况调整）。

---

## 第三条：明确性原则 (Clarity)

**核心：** 代码让人类可读。

- 错误须显式处理并附带上下文。
- 公共 API 须有清晰类型与文档（TypeScript 项目禁止随意 `any`）。
- 状态显式传递，避免隐式全局。

---

## 治理 (Governance)

本宪法效力高于 `AGENTS.md` 中与之冲突的条款，高于单次会话临时指令。计划与 spec 在评审时须做合宪性审查。
